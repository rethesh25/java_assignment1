# Restaurant Food Ordering System

## About the Project

This is a simple **Restaurant Food Ordering System** developed using **Java**.

The project demonstrates basic Java programming concepts by allowing users to select food items, enter quantities, and calculate the total bill.

## Features

* Display available food items
* Select food items
* Enter quantity
* Calculate the total price
* Display the final bill
* Simple and easy-to-understand Java code

## Concepts Used

This project mainly demonstrates:

* Java Classes and Objects
* Encapsulation
* Constructors
* Methods
* Variables and Data Types
* Conditional Statements
* Basic Input and Output

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/rethesh25/java_assignment1.git
```

### 2. Open the project

Open the `RestaurantFoodOrder` folder in:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

### 3. Compile the Java program

```bash
javac *.java
```

### 4. Run the program

```bash
java Main
```

> If the main class has a different name, replace `Main` with the name of that class.
